# GALA CRESTA

陣形・捕獲・合体・地上戦を全部のせた、レトロな縦スクロールシューティング。

**遊ぶ: https://naga3.github.io/galacresta/** （キーボードで操作します）

紹介動画: [media/promo.mp4](media/promo.mp4)

ビルド不要、外部ライブラリなし。`index.html` をブラウザで開いても遊べます。

## 操作

| キー | 動作 |
|---|---|
| 矢印 | 移動（画面の下半分を自由に動ける） |
| Z / Space | 連射 |
| Shift | 低速移動 |
| X | スネアビーム |
| C | オービット / ファイアバード |
| P | 一時停止（一時停止中の Esc でタイトルへ） |
| M | 音のオンオフ |

## 遊び方

- **編隊**: 敵は編隊で入場して陣形を組み、急降下してきます。
- **合体**: 地上の格納庫を壊すと番号つきのパーツ（2〜5）が出ます。拾うと合体して武器が増えます。
  2 左斜め / 3 右斜め / 4 貫通レーザー / 5 誘導ミサイル。被弾すると自機より先にパーツを失います。
- **トラクタービーム**: ピンクの隊長機はビームでパーツを奪います。その隊長機を撃ち落とすと取り返せます。
  自機ごと奪われたときは、取り返すと 2 機並んだツインファイターになります。
- **スネアビーム（X）**: 敵を吸い込んで、最大 6 機まで味方にします。虹色の敵や S 基地で補充できます。
- **オービット / ファイアバード（C）**: 敵を倒すとゲージがたまります。満タンで C を押すと、パーツが周りを回るオービットになります。
  4 パーツそろっていれば、無敵の火の鳥ファイアバードになります。
- **ボーナスステージ**: 撃ってこない 40 機を落とすボーナスアタックと、ゆっくりまっすぐ合体するドッキングがあります。

6 ステージとボーナス 4 回で 1 周です。周回するたびに敵が強くなります。

## ファイル

- `index.html` / `game.js` / `stages.js` … ゲーム本体。`stages.js` に全ステージの配置と設計の意図がある
- `tools/smoke.js` … ボットが自動で遊んで、例外やステージの詰まりがないか見る（`node tools/smoke.js --god`）
- `tools/shot.html` … 場面を指定して画面を確認する
- `tools/render-audio.js` … BGM を WAV/MP3 に書き出す
- `tools/record.js` … 紹介動画を作る（ヘッドレス Chromium と ffmpeg を使う）
